# v0.2.0 - Backend API and Testing Milestone



## Summary



This release upgrades the project from a static JPA data model into a runnable Spring Boot backend API for portfolio management.



The application now includes database configuration, sample data, repository interfaces, REST API endpoints, DTO responses, documentation, and automated tests.



## Added



- JPA repository interfaces for all portfolio management entities

- H2 in-memory database configuration

- Sample seed data for advisors, customers, portfolios, investment products, holdings, transactions, goals, risk profiles, recommendations, and appointments

- Read-only REST API controllers

- DTO response classes for cleaner JSON responses

- Spring Boot application context test

- Repository seed data test

- MockMvc API tests for advisor and portfolio endpoints

- README documentation for H2, API endpoints, DTOs, and testing

- CHANGELOG documentation for the backend API milestone



## Changed



- Converted the project from a static data model into a runnable backend API

- Updated API responses to avoid exposing deeply nested JPA entity graphs

- Improved the project’s portfolio value by adding tests, documentation, and runnable API behavior



## Fixed



- Fixed H2 shutdown warning by updating the database connection URL
